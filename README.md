# Basic Python Programs

This repository contains a collection of basic Python programs for beginners. Each program demonstrates a fundamental concept of Python programming, such as:

* Variables and Data Types
* Operators
* Conditional Statements (`if`, `else`, `elif`)
* Loops (`for`, `while`)
* Functions
* Lists
* Basic Object-Oriented Programming (OOP)

## Getting Started

1. Make sure you have Python installed. You can download it from [https://www.python.org/downloads/](https://www.python.org/downloads/).
2. Clone this repository or download the ZIP.
3. Open a terminal/command prompt and run the programs using:

```bash
python filename.py
```
